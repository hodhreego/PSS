2.2 FUNÇÕES - CONCEITOS FUNDAMENTAIS

📄

DEFINIÇÃO: Função é uma relação entre dois conjuntos onde cada entrada tem uma ÚNICA saída. Não pode haver um x com dois y diferentes!

Notação Matemática: f: A → B onde f(x) = y

• A (Domínio): Conjunto de ENTRADAS (valores de x que podemos usar)

• B (Contradomínio): Conjunto de possíveis SAÍDAS

• Imagem: Saídas que realmente ocorrem ⊆ Contradomínio

FUNÇÃO AFIM (OU LINEAR): f(x) = ax + b

• a = coeficiente angular (inclinação da reta) → a > 0: crescente | a < 0: decrescente

• b = coeficiente linear (onde corta eixo Y)

• Raiz: x = -b/a (onde a reta corta eixo X)

✓ EXEMPLO: f(x) = 2x + 3

• a = 2 (crescente), b = 3 (corta Y em 3), Raiz: x = -3/2 = -1,5

• f(0) = 3, f(1) = 5, f(2) = 7

FUNÇÃO QUADRÁTICA: f(x) = ax² + bx + c (a ≠ 0)

📐 Raízes (Bhaskara): x = (-b ± √Δ) / (2a) onde Δ = b² - 4ac

📌 Vértice: xᵥ = -b/(2a), yᵥ = -Δ/(4a) (máximo se a < 0, mínimo se a > 0)

✓ EXEMPLO: f(x) = x² - 4x + 3

• Δ = 16 - 12 = 4 → √Δ = 2

• Raízes: x = (4 ± 2)/2 = 3 ou 1

• Vértice: x = 2, y = 4 - 8 + 3 = -1 → V(2, -1)

🔍 CONCAVIDADE E ESTUDO DO SINAL:

a > 0: parábola com concavidade para CIMA (∪) — tem valor MÍNIMO no vértice.

a < 0: parábola com concavidade para BAIXO (∩) — tem valor MÁXIMO no vértice.

📌 Discriminante (Δ) e as raízes: Δ > 0 → duas raízes reais distintas | Δ = 0 → uma raiz real (dupla), a parábola tangencia o eixo X | Δ < 0 → nenhuma raiz real, a parábola não toca o eixo X.

🎓 EXERCÍCIO RESOLVIDO (Função Afim):

Questão: Uma corrida de táxi custa R$ 5 fixos + R$ 2 por km rodado. Escreva a função e calcule o custo de uma corrida de 12 km.

Solução: f(x) = 2x + 5 (x = km rodados). f(12) = 2(12) + 5 = 24 + 5 = R$ 29

🎓 EXERCÍCIO RESOLVIDO (Função Quadrática sem raízes reais):

Questão: A função f(x) = x² + 2x + 5 tem raízes reais? Justifique usando o discriminante.

Solução: Δ = b² - 4ac = 2² - 4(1)(5) = 4 - 20 = -16

Como Δ < 0, a função NÃO tem raízes reais — a parábola (concavidade para cima, pois a=1>0) não toca o eixo X, ficando inteiramente acima dele.
